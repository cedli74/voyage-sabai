# Voyage Sabai

Projet de site web statique avec architecture orientée serverless.

## Structure

- Frontend statique dans la racine du projet.
- Fonctions API dans le dossier `api/`.
- Intégrations externalisées dans `integrations/`.
- Données de prix centralisées dans `content/pricing.json`.

## Démarrage local

1. Ouvrir le dossier du projet.
2. Lancer `npm install`.
3. Démarrer un serveur local avec `npm run dev`.
4. Ouvrir http://localhost:3000.
